# ELECTRO-Q

## ECE Quiz & Assessment Platform

ELECTRO-Q is an ECE-focused quiz and assessment platform designed to help students practice core Electronics and Communication Engineering subjects through interactive quizzes and instant results.

## Project Overview

ECE students often need to practice questions from multiple subjects, but learning resources and practice questions can be scattered across different sources.

ELECTRO-Q aims to provide a dedicated platform where students can select an ECE subject, attempt MCQ-based quizzes, and evaluate their performance.

## Current Features

- Professional landing page
- ECE subject selection
- Interactive MCQ quiz
- Multiple-choice answer selection
- Question navigation
- Quiz progress indicator
- Score calculation
- Result screen
- Retry quiz functionality
- Responsive web interface

## Subjects

## Design Thinking & Innovation

The project follows Design Thinking and Innovation principles using:

- Mind Map
- Customer Journey
- Survey / Poll

These activities were used to understand student needs and identify problems related to ECE quiz practice.
